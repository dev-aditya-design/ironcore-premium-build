# IronCore Fitness Showcase

Create a premium, modern and fully responsive website for a fictional fitness business called "IronCore Fitness".

PURPOSE:

This website will be used as a professional web-development portfolio project, so make it look like a real high-end gym website, not a generic AI-generated template.

DESIGN:

- Premium dark fitness aesthetic

- Modern bold typography

- Strong visual hierarchy

- High-quality fitness/gym imagery

- Smooth scrolling and subtle animations

- Clean spacing

- Professional hover effects

- Fully responsive on desktop, tablet and mobile

- Fast and polished user experience

NAVIGATION:

Home

About

Programs

Trainers

Membership

Testimonials

FAQ

Contact

HERO SECTION:

Headline: "Build Strength. Build Confidence."

Subheading explaining IronCore Fitness as a premium training experience.

Add two CTA buttons:

"Start Your Free Trial"

"Explore Programs"

SECTIONS:

1. About IronCore Fitness

2. Training Programs:

   - Strength Training

   - Personal Training

   - Cardio & Conditioning

   - Transformation Program

3. Professional Trainers with realistic sample profiles

4. Membership plans with 3 pricing tiers

5. Member transformation/statistics section

6. Testimonials

7. FAQ

8. Contact section

9. Location and opening hours

10. Professional footer with social links

FEATURES:

- Floating WhatsApp contact button

- Contact form

- Book Free Trial CTA

- Smooth section navigation

- Mobile navigation menu

- Interactive membership cards

- Professional icons

- Strong CTA near the bottom

Use realistic professional sample content throughout the website.

Do not add unnecessary features, login systems, databases, dashboards or complex backend functionality.

The final result should be polished enough to show a potential freelance client as an example of a professional small-business website.
